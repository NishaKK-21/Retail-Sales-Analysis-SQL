# Retail Sales Data Analysis Using SQL

## Project Overview
This project focuses on analyzing retail sales data using MySQL to identify sales trends, customer purchasing patterns, and product category performance.

The analysis uses SQL queries to explore sales revenue, customer demographics, monthly sales, product categories, and customer spending behavior.

## Dataset
- **Dataset:** Retail Sales Dataset
- **Total Records:** 1,000 transactions
- **Time Period:** January 2023 – January 2024
- **Main Attributes:** Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Project Objectives
- Examine and validate the retail sales dataset.
- Analyze overall sales performance.
- Identify the highest-performing product categories.
- Understand customer purchasing behavior.
- Analyze monthly and weekday sales trends.
- Identify high-value customers.

## Data Cleaning and Validation
- Checked for missing values.
- Checked for duplicate transaction IDs.
- Identified invalid age and sales values.
- Verified total amount calculations.
- Checked date values and converted the Date column from TEXT to DATE.
- Validated distinct customer genders and product categories.

## SQL Analysis
The project covers 15 business questions using SQL concepts such as:

- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- COUNT, SUM and AVG
- CASE statements
- Date functions
- Subqueries
- HAVING
- DISTINCT
- LIMIT

## Key Findings
- **Total Revenue:** 456,000
- **Average Transaction Value:** 456
- **Highest Revenue Category:** Electronics (156,905)
- **Highest Transaction Count:** Clothing (351 transactions)
- **Highest Monthly Revenue:** May 2023 (53,150)
- **Highest Revenue by Gender:** Female customers (232,840)
- **Highest Revenue Age Group:** 46–55 (100,690)
- **Highest Revenue Weekday:** Saturday (78,815)
- **Highest Average Transaction Value by Category:** Beauty (467.48)

## Business Recommendations
- Focus on Electronics to maintain and improve revenue performance.
- Use targeted promotions to increase Beauty category sales.
- Develop customer-focused marketing strategies based on purchasing patterns.
- Explore Saturday promotions to make use of the observed high-revenue day.
- Introduce loyalty offers to encourage repeat purchases and retain high-value customers.

## Conclusion
This project demonstrates how SQL can be used to clean, analyze, and interpret retail sales data. The analysis provides useful insights into product performance, customer behavior, and sales trends that can support better business decisions.
